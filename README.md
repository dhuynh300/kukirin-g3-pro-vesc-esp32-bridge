# Kukirin G3 Pro VESC ESP32 Bridge

ESP32 firmware that connects the Kukirin G3 Pro scooter's TFM13-FEIMI-1 display to two VESC motor controllers, plus the LispBM powertrain script that runs on the rear VESC.

Documentation is in progress.

## Build

```bash
pio run
```
